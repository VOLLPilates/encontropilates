# Encontro Brasileiro de Pilates

Site em HTML/CSS/JS puro do 11º Encontro Brasileiro de Pilates 2026.

## Estrutura

- `index.html` — home (todas as sections principais).
- `palestrantes/index.html` — subpágina de palestrantes + convidados VIP.
- `local/index.html` — subpágina de local + tour em vídeo.
- `assets/css/styles.css`, `assets/js/main.js` — folha de estilos e scripts compartilhados por todas as páginas.
